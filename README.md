# 会見録チェッカー

文字起こしした記者会見録（Word）を、職場の表記メモに沿ってチェックするツールです。
**本文は書き換えません。** 左に Word の本文、右に修正箇所（修正候補・理由）を並べて表示し、
直すかどうかは担当者が判断します。

## 使い方

1. `index.html` をブラウザ（Edge / Chrome）で開く（インストール不要・オフラインで動作）
2. 「Wordを開く」で `.docx` を選ぶ（ドラッグ＆ドロップ、テキスト貼り付けも可）
3. 会見の種別（定例記者会見／お出かけ知事室）を選ぶ。本文の冒頭に種別名があれば自動で切り替わります
4. 右の一覧をクリックすると本文の該当箇所へ移動します。本文の色付き箇所をクリックすると一覧側へ移動します
5. 確認したものは「確認済み」、直さないものは「対象外」に。「一覧をコピー」でメールや Word に貼り付けられます

- `J` / `K` キーで次／前の箇所へ移動
- 「要確認」の付いた指摘は、文脈によっては直さないものです
- Word ファイルはブラウザの中だけで読み込み、外部には送信しません
- 旧形式の `.doc` は読めません。Word で `.docx` として保存し直してください

## チェック内容（表記メモより）

| 分類 | 内容 |
| --- | --- |
| 話者表記 | 定例記者会見：幹事者は【】なし ／ お出かけ知事室：発言者は【】あり |
| 表記統一 | 中→なか、時→とき、既→すで、是非→ぜひ、作り→づくり、作る→つくる、一人→ひとり、目がけて→めがけて、受け止め→受けとめ、形→かたち、分かる→わかる（分かれるはそのまま）、一つ目 |
| 重複 | どんどんどんどん→どんどん など同じ語の繰り返し |
| 削除候補 | 実際、もう、いわゆる、（文頭の）では |
| 話し言葉 | ついていたんで→ついていたので、これによって→これにより、〜とか→〜と、〜ていう→〜という |
| 資料表記 | 資料にある「」付き・中点付きの語はそのまま使う（九州・山口、「ブルゴーニュ」）。「」の中と中点でつながった語は他のチェックの対象外 |
| 記号・空白 | 、、や 。。 の重なり、文中の空白 |

## 今月の用語（だれでも追加できます）

その月だけ使う固有名詞（例：熊本こころのケアセンター）は、`今月の用語.txt` に書きます。
ルール（`js/rules.js`）を触る必要はありません。

1. チェッカーのフォルダにある `今月の用語.txt` をメモ帳で開く
2. 「ここから」と「ここまで」の間に1行に1つ書いて上書き保存
3. チェッカーを開き直すと反映（共有フォルダに置けば全員に反映）

```
熊本こころのケアセンター                          … 正しい表記だけ書く
熊本心のケアセンター→熊本こころのケアセンター    … 誤りやすい表記を指定する
# 2026年10月                                     … # から後ろはメモ
```

- 書いた語はほかのチェックの対象外になります（「こころ」などに指摘が出ません）
- 正しい表記だけ書いた場合も、途中のひらがな・漢字だけが違う表記（熊本心のケアセンター など）を「要確認」として指摘します
- 読み込めたかどうかは、画面左下の「今月の用語：○語」で確認できます（クリックで一覧）

## ルールの追加・変更

- 画面の「ルール」から、資料表記・追加ルール（`検出→候補 # メモ`）・除外語を登録できます（このブラウザに保存）
- 組み込みルールは `js/rules.js` に定義しています。職場全体で使うルールはここを編集してください

## 構成

```
index.html                 画面
css/style.css              見た目
js/rules.js                表記ルール
js/checker.js              検出エンジン（本文は変更しない）
js/app.js                  画面の動作
今月の用語.txt             その月の用語（メモ帳で編集）
vendor/mammoth.browser.min.js  Word(.docx)読み込み（mammoth.js, BSD-2-Clause）
test/                      テスト（node test/checker.test.js）
```
